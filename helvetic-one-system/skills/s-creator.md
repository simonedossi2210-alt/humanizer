# S.CREATOR — Content Generation Skill (Helvetic.one / Camper-Vanlife)

## Quando usarla
- Hai un segnale da S.SIGNAL o un brief cliente e serve trasformarlo in contenuto pronto.
- Serve uno script per Reel/TikTok, una caption, o una serie di varianti hook.

## Input richiesti
1. Segnale/trend o brief (testo)
2. Piattaforma target (TikTok / Instagram / Facebook)
3. Tono di voce: diretto, tecnico ma umano, no fuffa
4. Obiettivo (awareness / lead / vendita diretta)

## Vocabolario di nicchia (usare con naturalezza)
conversione camper, van life, furgone attrezzato, impianto elettrico 12V/24V, pannello solare, isolamento termico, letto basculante, cucina camper, omologazione svizzera per camper.

## Calendario stagionale (per decidere il tipo di contenuto)
- **Feb-Apr**: prep primavera — contenuti su preparazione mezzo per stagione.
- **Mag-Set**: vanlife/viaggi — "on the road", testimonianze clienti in viaggio.
- **Ott-Gen**: contenuti tecnici/officina (isolamento, impianti elettrici, manutenzione invernale) — meno competizione, buon momento per authority content.

## Processo
1. **Hook first**: 3 varianti di hook (prime 3 secondi). Pattern-interrupt o domanda diretta, mai apertura generica.
2. **Corpo**: beat da 5-7 secondi (video) o paragrafi brevi (caption). Ogni beat regge da solo.
3. **CTA**: una sola, coerente con l'obiettivo.
4. **Output**: script formattato per OpenShorts (timing per scena) o caption pronta.

## Regole ferree
- Niente frasi motivazionali vuote.
- Claim tecnici (capacità batterie/pannelli, tempi conversione) sempre verificabili, mai arrotondati per sembrare migliori.
- Prezzi: sempre IVA inclusa, coerenti con l'audit OIP già fatto su Helvetic.one.

## Output atteso
Blocco markdown: Hook (3 varianti) → Corpo → CTA → Note per S.EDITOR (cosa verificare).
